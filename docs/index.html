Instalación en dos pasos

Descarga el paquete e instálalo con el gestor de paquetes. El icono de la app aparece automáticamente en el menú.

# 1. Descarga
wget -c https://github.com/masterhdez/LaBibliaSv/releases/latest/download/la-biblia-sv_1.0.0_amd64.deb

# 2. Instala
sudo apt install ./la-biblia-sv_1.0.0_amd64.deb

# Listo — abre "La Biblia Sv" desde el menú
la-biblia-sv

# Para desinstalar
sudo apt remove la-biblia-sv

Dependencias necesarias (se instalan automáticamente): python3, python3-gi, gir1.2-gtk-3.0, gir1.2-pango-1.0, python3-cairo y gir1.2-webkit2-4.1 (o 4.0).
